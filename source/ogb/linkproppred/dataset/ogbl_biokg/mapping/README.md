# ogbl-biokg

## relidx2relname.csv.gz

Mapping from relation index to relation name.


## Entity mappings

Below, we have entity mapping for each of the 5 entity node types.

### disease_entidx2name.csv.gz 

For the disease node type, the file contains the mapping from entity index to disease ID, c.f., UMLS CUI (https://www.nlm.nih.gov/research/umls/index.html).

### drug_entidx2name.csv.gz 

For the drug node type, the file contains the mapping from entity index to drug ID, c.f., STITCH ID (http://stitch.embl.de/).

### function_entidx2name.csv.gz  

For function node type, the file contains the mapping from entity index to protein function ID, c.f., Gene Ontology ID (http://geneontology.org/).

### protein_entidx2name.csv.gz  

For protein node type, the file contains the mapping from entity index to protein ID, c.f., Proteins: Entrez Gene ID (https://www.genenames.org/).

### sideeffects_entidx2name.csv.gz

For side effects node type, the file contains the mapping from entity index to side effects ID, c.f., UMLS CUI (https://www.nlm.nih.gov/research/umls/index.html).
